# myEPG: AMJ2026

Planning dashboard for Arts & Music Fest 2026 — schedule, budget, logistics, publicity, programme, booths and team.

**Live site:** https://cneakyinks.github.io/ajm-management-dashboard/

Edits made in the app are saved in your own browser (localStorage), so each person's changes stay on their device.

## Run locally

```sh
pnpm install
pnpm dev
```

Pushing to `main` rebuilds and redeploys the live site automatically.
